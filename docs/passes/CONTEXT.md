## Что делает

1. В Bitrix24, в поле ввода диалога **открытой линии**, есть кнопка «🎫 Оформить пропуск» (в ряду значков рядом с «Быстрыми ответами»). В обычных чатах и CRM-чатах её нет.
2. В окне вставляешь список ФИО (как прислал клиент), выбираешь дату: «Сегодня», «Завтра» (по умолчанию) или своя дата. Подтверждение внутри окна: «Да, оформить».
3. Скрипт открывает **фоновую вкладку** my.avanguard.pro (`/account/354/guests`), там по очереди: «Новый посетитель» → ФИО → дата в «с» и «по» → номер машины, если есть → «Сохранить».
4. В Bitrix у каждого имени ✓ или ✗. На первой ошибке скрипт останавливается. Вкладка Авангарда закрывается сама.
5. На странице посетителей Авангарда есть такая же панель (тоже одна дата).

## Разбор списка

- Разделители: новая строка, «;», «,». Нумерация «1.», «2)», «-», «•» срезается, повторы убираются.
- Номер машины ищется в строке: «Е334ав34», «A 123 BC 777 RUS». Латиница переводится в кириллицу, регион 2–3 цифры. Пример: «Иванов Иван a123bc 777» → «Иванов Иван · А123ВС 777».
- Номер отдельной строкой цепляется к первому ФИО без машины. Если такого ФИО нет, пропуск оформляется на «Машина».
- С 1.3.2 буквы номера любые. Если есть буквы не с обычных номеров (например «Б» в Е334аб34), скрипт ставит галочку «Использовать специальный номер».
- Строки с цифрами, но без понятного номера, не оформляются (показываются как ошибочные).

## Как устроено внутри

- Bitrix и Авангард общаются через хранилище Tampermonkey: Bitrix кладёт задание `{id, names, from, to}`, вкладка Авангарда пишет результат по каждому имени.
- `@run-at document-start`, подмена `requestAnimationFrame` скриптом в мире страницы: иначе в фоновой вкладке сайт не перерисовывает таблицу.
- Сайт при загрузке уходит на /login и обратно, хвост `#s1826-job=…` теряется. Поэтому задание берётся «по свежести» (до 45 с) и через sessionStorage. Если через 10 с списка нет, вкладка сама переходит на страницу посетителей.
- В окне «Новый посетитель» обе даты по умолчанию сегодня, а «с» позже «по» сайт откатывает. Поэтому даты ставятся в порядке «по», «с», «по».
- Проверка «уже есть пропуск» удалена в 1.3.1 по решению Ильи: пропуск оформляется **всегда**.
- Версия в `@name` («v1.3.2 …»), `@version` и `VERSION`; тест сверяет их. Тесты: `node --test tests/*.test.js` (72 из 72 на main). Вариант `node --test tests/` в контейнере не работает, нужен шаблон.

## 1.4.0 (25.10): API сайта вместо кликов

- API: `https://api.avanguard.pro/api/`, заголовок `authorization: Bearer <localStorage.access_token>` (простая строка). Скрипт берёт ключ на странице Авангарда и шлёт только в API Авангарда, наружу не показывает.
- Оформление: `POST guests` {accountId: "354" строкой, name, type: "full", dateStart/dateFinish = начало/конец местного дня в ISO UTC с Z, login: "", carNumber, carRegion}. Спецномер — тот же carNumber без маски, отдельного поля нет. Ответ с `error: true` = ошибка даже при 200.
- «✓ оформлен» только если после POST новый пропуск нашёлся в `GET guests?search=<фамилия>&dateStart=…T00:00:00&dateFinish=…T23:59:59`. Перед оформлением показывается, был ли пропуск на этот день (не мешает оформлению).
- Времена в ответах — UTC без «Z» (пропуск на 25.10 = 24.10 21:00 … 25.10 20:59:59).
- Журнал проходов: `log/access?subjectAccountId=354&entityType=guest&start&finish&pageSize=500` (с accountId — пусто). Событие: time, event (код), eventName, entity.id = id пропуска. Машины: 21–38 (нечётные въезд, чётные выезд), 1/2 — пешие «Вход/Выход», не считаем.
- Колонка «Сегодня» между «Период» и «Статус». Строка ↔ пропуск по ячейкам ФИО и «Автомобиль» среди всех ответов сайта (их копирует скрипт в мире страницы). Сайт берёт прежние списки из кэша без запроса — тогда скрипт сам запрашивает то, что на экране.
- Код для мира страницы — шаблонная строка: `\/` в ней теряет `\`, регулярки там не писать (тест проверяет разбор).
- ФИО пишется с заглавной (строчные и КАПС), инициалы не трогаются.
- Поиск в таблице сайта срабатывает только по Enter.
- Живые тесты 1.4.0 прошли: тестовые пропуска 27.10 (1267480, 1267481, 1267483), 28.10 (1267490, 1267491), 30.10 (1267494). Не удаляли.

## 1.4.1: список сразу в поле

- По нажатию кнопки (в линии и в Авангарде) в поле попадает выделенный текст (запоминается на pointerdown), иначе, если поле пустое, скопированный (`navigator.clipboard.readText`).
