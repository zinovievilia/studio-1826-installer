# CONTEXT — Studio1826Updater (исходники DMG)

Рабочая память по приложению. Обновлено 26.10.2026: в `main` код 4.4.1; выложенный DMG/app.version — 4.3.0
(4.4.1 собран на Mac Ильи, ждёт проверки отправки дебага и его «выкладывай 4.4.1»).
Пользовательское описание — `README.md` этой папки. Userscript (`studio1826.user.js`) здесь не меняем.

## Что это

macOS 13+ (SwiftUI + AppKit), бандл `Studio1826Updater.app`, id `studio1826.updater`. С 4.0.0 — не только
обновлятор: клик по значку — поповер 460×660 с вкладками Скрипты · Касса · Ссылки · Настройка, выбор браузера
в шапке, «Проверить обновления» внизу; правый клик — NSMenu; ⌃⌥Пробел — панель быстрых ответов поверх любого окна.

## Решения 4.0.0 (почему так)

- **Всё под значком (4.1)**: в 4.0 было отдельное окно — Илье больше нравится поповер «как раньше», окно убрано.
  Редактор скрипта и подтверждения — внутри поповера (без sheet/alert, они конфликтуют с transient-поповером);
  на время NSSavePanel/NSOpenPanel поповер закрепляется (`PopoverPin`).
- **Быстрые ответы**: Carbon `RegisterEventHotKey` (без разрешений) + `NSPanel` `.nonactivatingPanel` — браузер остаётся
  активным, после Enter курсор там же. Вставка — CGEvent ⌘V, требует Accessibility (`AXIsProcessTrusted`); без него — только копирование.
  Подсказки по тексту клиента автоматически (без хоткея) возможны только в userscript — он видит чат; это задача того направления.
- **Меню «Правка»** (`ensureEditMenu`) — без него в полях не работают ⌘C/⌘V у LSUIElement-приложения.
- **Браузер выбирается первым** (`BrowserService.selected`, UserDefaults `selectedBrowser`); шаги настройки зависят от него.
- **Tampermonkey**: скрипт ставится открытием raw-URL в браузере (Tampermonkey перехватывает `.user.js`), дальше обновляет
  по `@updateURL` сам. Старая логика записи файла в папку расширения Chrome удалена — Tampermonkey хранит скрипты не файлами.
  Наличие ищется по ID `dhdgffkkebhmkfjojejmpbldmpobfkfo` / `gcalenpjmijncebpfijmoaglllgpjagf` или `manifest.json` с именем Tampermonkey
  во всех профилях (`Google/Chrome`, `Yandex/YandexBrowser`, `com.operasoftware.Opera[GX]`). Есть ручная галочка на случай, если не нашёл.
- **Safari**: как раньше — файл в контейнер Userscripts, по графику. Добавлено: пишем, только если скачан настоящий userscript
  (`==UserScript==`) и HTTP 200.
- **Самообновление**: `app.version` сравнивается семантически (`AppVersion.isNewer`), не «!=» — иначе 4.0.0 до выкладки
  DMG предлагала бы «обновиться» на 3.0.0. Перед заменой проверяется, что в DMG не пустой `.app`.
- **Скрипты ответов**: базовая библиотека `Resources/ReplyLibrary.json` (id `studio.*`) + слой пользователя
  `~/Library/Application Support/Studio1826/replies.json` (свои `my.*`, правки базовых со снимком версии студии, скрытые базовые).
  Служба «Сохранить как скрипт 1826» (`AppDelegate.saveScript`, `NSServices`) кладёт текст в `ReplySearchState.draftText` → редактор.
  Повреждённый файл не затирается, а откладывается рядом. Обмен — JSON `{format, version, scripts}`; импорт берёт любой JSON с `scripts`.
- **Автозапуск**: `Services/LaunchAtLogin.swift` (`SMAppService.mainApp`). При каждом запуске из `/Applications` или `~/Applications` включается сам, если сотрудник не выключил его вручную (`launchAtLoginDisabledByUser`, пишется только переключателем/пунктом меню). Сборки вне «Программ» (build-local, DMG, Загрузки) не регистрируются. На Mac не проверялся — проверить на установке из DMG.
- **Ссылки**: `Core/LinksLayout.swift` (разделы/строки, перестановки, `merge(studio:)` по `knownStudioIDs`) + `LinksStore` (`links.json`).
  Перетаскивание — `.draggable`/`.dropDestination` со строками `group:`/`item:`. Правый клик собирает разделы в `menuNeedsUpdate`.
- **Отчёт по кассе**: `Calculator` на `Decimal`; «2.000» = тысячи (точка + ровно 3 цифры, первая группа не с 0), «1,5»/«1.5» — дробь;
  формат вывода «102.690», дробь через запятую. С 4.2: пустое поле = 0, блокирует только поле с ошибкой; окно без прокрутки.
  С 4.2.1 копируется обычный текст (обёртка ``` в Telegram показывалась кавычками, а не моноширинным).

## Решения 4.2–4.4 (25.10.2026)

- **Вставка не работает при включённой галочке**: ad-hoc подпись (`codesign --sign -`) даёт каждой сборке новый cdhash,
  TCC держит старую запись, `AXIsProcessTrusted()` = false. Кнопка «Сбросить и разрешить заново» →
  `tccutil reset Accessibility <bundle id>` + повторный запрос (`QuickReplySettings.resetPastePermission`). Проверка раз в секунду.
- **Safari «You don't have permission to save… scripts»** (4.3.0): то же для `kTCCServiceSystemPolicyAppData`
  (журнал tccd: authValue=0, authReason=2 — сохранённый запрет). Кнопка «Сбросить доступ» у скрипта →
  `tccutil reset SystemPolicyAppData` + повторная установка (`BrowserService.resetAppDataPermission`). Права папки при этом в порядке.
  Корень обеих проблем — ad-hoc подпись; постоянный самоподписанный сертификат в build.sh снял бы её (не сделано).
- **Скрипты ответов без ключевых слов** (4.2.0): поле убрано из редактора; `ReplySuggest.rank` весит слова текста ×2
  (ключевые ×3, название ×2), порог ≥3. Старые ключевые слова при сохранении не теряются.
- **Яндекс Браузер**: страница расширений `browser://extensions` (не `browser://tune`).
- **Дебаг** (4.3.0, `Core/DebugReport.swift` + `Services/DebugLog.swift`): журнал ошибок `debug-events.json` (100 последних),
  автоотчёт при `DebugLog.record` (раз в 30 мин на одну ошибку, 20 файлов в `…/Debug`), кнопка «Сохранить дебаг в «Загрузки»».
  Без текстов скриптов и сумм кассы. Пишут в журнал: ошибки скриптов, проверки и установки обновления, tccutil.
- **Отправка дебага** (4.4.x): PUT в `zinovievilia/studio-1826-debug` (приватный), `reports/<NSUserName>/<файл>`.
  Ключ — fine-grained PAT только на этот репо (Contents R/W), лежит в `~/.studio1826/debug-token` (600), вводится в поле
  «Ключ для отчётов». 4.4.0 вписывал ключ в Info.plist сборки — **не выкладывался**: DMG публичный, ключ достал бы любой,
  а GitHub мог бы его отозвать. Связка ключей не используется: у ad-hoc сборки после обновления был бы запрос пароля.
  Ошибки отправки — только в NSLog (иначе петля отчётов). Ключ Ильи на его Mac создан им самим (Claude ключи не выпускает).

## Выпуск (как делаем сейчас)

PR в `main` → зелёный CI → сборка на Mac Ильи (`~/ClaudeCode/studio-1826-installer-pr`, `bash ./build.sh`) →
загрузка через веб-интерфейс GitHub во встроенном браузере Claude на Mac (git push с Mac невозможен — нет учётки):
корневой DMG → корневой `app.version` → копии в `Studio1826UpdaterDMG/` → проверка raw. Коммит в `main` — только после
дословного «выкладывай X.Y.Z» от Ильи. DMG собирается только на Mac (в облаке Linux).
