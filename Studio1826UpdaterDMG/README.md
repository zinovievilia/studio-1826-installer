# Studio 1826 Updater

Menu bar приложение для macOS. Автоматически обновляет userscript студии 1826
и умеет обновлять само себя через GitHub Releases.

---

## Требования

- macOS 13 Ventura или новее
- Xcode (из App Store, бесплатно)
- [Userscripts для Safari](https://apps.apple.com/app/userscripts/id1463298887) — само расширение

---

## Сборка и установка

### 1. Установить Xcode

Если ещё не установлен:

```bash
open "https://apps.apple.com/app/xcode/id497799835"
```

После установки переключить активный инструмент:

```bash
sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
```

Проверить:

```bash
xcodebuild -version
# Xcode 15.x ...
```

### 2. Собрать приложение

**Проверить в Xcode (без DMG):** открыть `Studio1826Updater.xcodeproj` → вверху выбрать схему
`Studio1826Updater` и «My Mac» → **Product → Run** (⌘R) → значок появится в строке меню. Все файлы
(папки `Core`, `Services`, `Views`, `Resources`) уже подключены в проекте.

**Собрать DMG для выкладки:**

```bash
cd Studio1826UpdaterDMG
chmod +x build.sh
./build.sh
```

Скрипт скомпилирует `.app` и упакует в `Studio1826Updater.dmg` в той же папке.

### 3. Установить

1. Открыть `Studio1826Updater.dmg`
2. Перетащить `Studio1826Updater.app` в папку `Applications`
3. При первом запуске macOS покажет предупреждение — это нормально без подписи Developer ID:

```
Правый клик на .app → Открыть → Открыть
```

Предупреждение появится только один раз.

### 4. Добавить в автозапуск

**Системные настройки → Основные → Объекты входа в систему** →
нажать `+` → выбрать `Studio1826Updater.app`.

## Что делает приложение (версия 4.4)

Значок 1826 Studio в строке меню. **Клик** — окно под значком с вкладками
**Скрипты · Касса · Ссылки · Настройка**, вверху справа выбор браузера, внизу «Проверить обновления» и выход.
**Правый клик** — короткое меню (скрипты, отчёт, ссылки филиалов, таблица зарплаты, обновления, выход).
При первом запуске окно открывается само на вкладке «Настройка».

### Быстрые ответы — ⌃⌥Пробел

В любом приложении (например, в открытой линии Bitrix24) ⌃⌥Пробел открывает поиск по скриптам ответов поверх окна. Справа полный текст: можно выделить мышкой кусок — ⌘C или ↩ возьмут только его.
Слово → ↑↓ → Enter: ответ вставляется туда, где стоит курсор. Для вставки нужно разрешение
«Универсальный доступ» (кнопка во вкладке «Настройка» → «Быстрые ответы»); без него ответ копируется, вставить ⌘V.
С ad-hoc подписью macOS после обновления приложения держит старую галочку, но доступа не даёт — выключить-включить не помогает.
Нажмите **«Сбросить и разрешить заново»** во вкладке «Настройка» (или «Сбросить» в панели) и снова включите Studio1826Updater в «Универсальном доступе».

### Вкладка «Настройка»: браузер и расширения

Сначала выбирается браузер (Safari, Chrome, Яндекс Браузер, Opera). После этого — пошаговая
настройка с раскрывающимися шагами; выполненные шаги отмечаются зелёной галочкой, первый
невыполненный раскрыт.

- **Safari**: установить Userscripts (кнопка открывает App Store) → запустить Userscripts один раз →
  включить расширение в Safari → установить скрипты студии (приложение кладёт файл в папку Userscripts) →
  проверить в Bitrix24. Установку Userscripts и наличие папки приложение проверяет само.
- **Chrome / Яндекс / Opera**: браузер установлен → Tampermonkey (кнопка открывает страницу магазина
  в этом браузере; приложение находит Tampermonkey в папках профилей) → разрешить пользовательские скрипты
  (адрес страницы расширений копируется кнопкой) → установить скрипты студии (скрипт открывается в браузере,
  Tampermonkey предлагает «Установить») → проверить в Bitrix24.

Само ставить расширения macOS и браузеры не разрешают: приложение открывает нужную страницу,
кнопку «Установить» нажимает человек. Шаги, которые проверить нельзя, отмечаются галочкой вручную.

Список скриптов студии — `StudioUserscript.all` в `Core/Studio.swift`: **Основной** (`studio1826.user.js`)
и **Пропуска списком** (`studio1826-passes.user.js`). Страница расширений Яндекс Браузера — `browser://extensions`.

**Safari: «You don't have permission to save the file…»** — macOS запомнила запрет на запись в папку Userscripts
(«Данные других приложений»), часто после обновления приложения. У скрипта появляется кнопка **«Сбросить доступ»**:
она удаляет только запись нашего приложения (`tccutil reset SystemPolicyAppData studio1826.updater`), macOS спрашивает снова —
нажмите «Разрешить».

### Автообновление скриптов (Safari)

Файл: `~/Library/Containers/com.userscripts.macos.Userscripts-Extension/Data/Documents/scripts/studio1826.user.js`,
источник: `https://raw.githubusercontent.com/zinovievilia/studio-1826-installer/main/studio1826.user.js`.
График 2/2 / каждый день (по умолчанию) / только будни / вручную, интервал 1–24 ч (карточка «Автообновление скриптов»).
Файл перезаписывается, только если скачан настоящий userscript (есть `==UserScript==`) и версия отличается.
В Chrome/Яндекс/Opera скрипт обновляет сам Tampermonkey по `@updateURL`.

### Автозапуск

Приложение само добавляет себя в «Объекты входа» (`SMAppService`, macOS 13+) при каждом запуске из «Программ», пока вы не выключили
автозапуск вручную. Выключить можно в «Настройке» (переключатель сверху) или в меню по правому клику: «Запускать при входе в систему» —
после этого приложение его не включает. Из образа DMG, «Загрузок» и папок сборки автозапуск не включается: сначала перетащите приложение
в «Программы» и откройте оттуда. Если macOS просит подтверждения, в «Настройке» появится кнопка «Открыть настройки».

### Ссылки — настраиваются

«Изменить» во вкладке «Ссылки»: свои строки (ссылка, телефон или любой текст — тип определяется сам),
у каждой строки включается/выключается кнопка «Скопировать», строки и разделы перетаскиваются за ⠿
(или «Выше/Ниже» в меню), разделы переименовываются и удаляются, «Вернуть как у студии» сбрасывает всё.
Хранится в `~/Library/Application Support/Studio1826/links.json`; новые ссылки студии из обновлений
добавляются в конец, удалённые сотрудником не возвращаются. Меню по правому клику показывает те же разделы.

### Скрипты ответов

Клик по скрипту (или Enter) в окне под значком копирует его и сразу вставляет в поле, где вы печатали до открытия окна
(нужны «Вставлять сразу» и «Универсальный доступ»; иначе — только копирует). В меню правой кнопки по строке — «Скопировать текст» без вставки.

Ключевые слова отдельно не заполняются: поиск и подбор по сообщению клиента идут по словам из названия и текста скрипта.

Библиотека готовых ответов клиентам: поиск на всю ширину (все слова, «ё» = «е»), категории, кнопка копирования
в каждой строке, клик — скрипт целиком; свои скрипты, правка, дублирование, удаление, экспорт/импорт `.json` для коллег.

- Новый скрипт из любой программы: выделить текст → правая кнопка → «Сохранить как скрипт 1826»
  (служба macOS, `NSServices` в Info.plist; может быть в подменю «Службы», включается в
  Системные настройки → Клавиатура → Сочетания клавиш → Службы). Открывается редактор с этим текстом.
- Базовая библиотека студии — `Studio1826Updater/Resources/ReplyLibrary.json`, приходит с обновлением приложения.
  Чтобы поменять общие скрипты для всех — править этот файл и выпускать новую версию.
- Своё хранится на каждом Mac: `~/Library/Application Support/Studio1826/replies.json`.
  Обновление приложения его не трогает. Изменённый скрипт студии остаётся в версии сотрудника; если студия
  выпустила новый текст, появляется отметка «Взять версию студии / Оставить мою». Удалённые скрипты студии
  возвращаются через «Ещё» → «Вернуть удалённые скрипты студии».

### Отчёт по кассе

Дата (сегодня), филиал, Изъятие / Внесение / Наличные / Денежный ящик / Касса. В полях можно считать:
`100+500`, `2.000+410`, `(100+50)*2`, `900:3`. «2.000» с точкой перед тремя цифрами — это тысячи,
`1,5` или `1.5` — дробь. Пустое поле считается нулём. Всё помещается в окно без прокрутки.
Кнопка «Скопировать для Telegram» (⌘↩) кладёт в буфер обычный текст (без ``` — Telegram показывал его кавычками):

```
23.10
Павелецкая

Изъятие: 0
Внесение: 2.000
Наличные: 410
Денежный ящик: 102.690
Касса: 102.730
```

### Если что-то не работает — дебаг

В «Настройке» → «Если что-то не работает» кнопка **«Сохранить дебаг в «Загрузки»»**: файл с версией приложения и macOS,
браузером, состоянием папки Userscripts, статусом скриптов, разрешениями и последними ошибками. Тексты скриптов ответов
и суммы кассы туда не попадают. При ошибках скриптов и обновлений дебаг собирается сам в
`~/Library/Application Support/Studio1826Updater/Debug` (не чаще раза в 30 минут на одну ошибку, хранится 20 последних).

Если на Mac есть ключ для отчётов, каждый дебаг ещё и уходит в приватный репозиторий `zinovievilia/studio-1826-debug`
(`reports/<пользователь Mac>/<файл>.txt`). Ключ — fine-grained token только на этот репозиторий (Contents: read and write).
Он **не** зашивается в DMG (репозиторий установщика публичный): вставляется один раз в поле «Ключ для отчётов» и лежит в
`~/.studio1826/debug-token` (права 600). Без ключа дебаг просто остаётся на Mac.

### Сайт и ссылки

Залы, оборудование, как пройти, бронирование — для Павелецкой и Серпуховской; каждую ссылку можно открыть
или скопировать для клиента, «Все ссылки» копирует список филиала. Таблица зарплаты и Bitrix24.

### Обновление приложения

Кнопка **Проверить обновления** внизу слева (и в меню значка) проверяет и приложение, и скрипты.
Приложение сравнивает `app.version` в репозитории со своей версией и предлагает установку,
только если версия в репозитории **новее** (раньше предлагало при любом отличии). Установка: скачать
`Studio1826Updater.dmg` из репозитория → смонтировать → проверить, что `.app` не пустой → заменить
`/Applications/Studio1826Updater.app` → перезапуск.

## Тесты

Чистая логика (калькулятор, формат отчёта, версии, библиотека скриптов, ссылки) лежит в
`Studio1826Updater/Core` и не зависит от AppKit. Проверка на Mac:

```bash
swiftc -swift-version 5 Studio1826Updater/Core/*.swift Tests/CoreTests/main.swift -o /tmp/coretests && /tmp/coretests
```

То же самое плюс сборку приложения делает GitHub Actions (`.github/workflows/updater.yml`) при изменениях
в этой папке.

## Как выпускать обновления приложения

Приложение читает `app.version` и `Studio1826Updater.dmg` из корня ветки `main` (raw GitHub, кэш до ~5 минут). Релизы GitHub не нужны.

1. Изменения — PR в `main`, слияние после зелёного CI (`updater.yml`: тесты Core + сборка на macOS).
   Версию поднять в трёх местах: `APP_VERSION` в `UpdaterService.swift`, `Info.plist`, `MARKETING_VERSION` в `project.pbxproj`.
2. Собрать на Mac из свежего `main`: `bash ./build.sh` — пишет `Studio1826Updater.dmg` и `app.version`.
3. Загрузить в `main` строго по порядку: корневой `Studio1826Updater.dmg` → корневой `app.version` →
   копии в `Studio1826UpdaterDMG/`. Если загрузить `app.version` раньше DMG, приложения скачают старый DMG.
4. Проверить: `raw…/main/app.version` отдаёт новую версию, DMG скачивается того же размера, что собранный.

## Устранение проблем

**«xcode-select: error: tool requires Xcode»**
```bash
sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
```

**«Не удалось открыть, так как Apple не может проверить»**
```
Правый клик на .app → Открыть → Открыть
```
Или снять карантин:
```bash
xattr -cr /Applications/Studio1826Updater.app
```

**Скрипт не обновляется — папка не существует**

Расширение Userscripts нужно открыть хотя бы раз в Safari, чтобы она создала
свою папку Documents. После этого обновление заработает.

**Приложение не видит обновление**

Проверить, что `app.version` в корне `main` содержит новую версию (raw кэшируется до ~5 минут) и что DMG загружен до него.

**Не работает вставка, хотя «Универсальный доступ» включён** — «Настройка» → «Сбросить и разрешить заново».

**Safari: «You don't have permission to save…»** — кнопка «Сбросить доступ» у скрипта, затем «Разрешить».
